# Inkwell Notes

A simple, ad-free handwriting notes app for iPad and Apple Pencil. It runs in Safari and installs to the Home Screen like a normal app.

- Notebooks (paged) and whiteboards (endless canvas)
- Fountain pen, ballpoint, highlighter, eraser, lasso, text, photos
- Tap a selected tool again to open its settings
- Pressure, tapered strokes, smoothing, palm rejection, hold-to-straighten
- Two-finger tap = undo, three-finger tap = redo
- Works offline. Notes are saved on the device only.

## Install on iPad
1. Open the site in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open **Inkwell** from the Home Screen.

## Files
- `index.html` — the whole app
- `sw.js` — offline support. Bump `VERSION` after each change so iPads update.
- `manifest.webmanifest`, `icons/` — Home Screen name and icon
